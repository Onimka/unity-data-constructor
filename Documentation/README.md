# Data Constructor — Documentation

A visual editor for creating, managing and serializing structured game data in Unity. Start with **First Launch**, then dive into whichever area you need.

## 📑 Table of Contents

1. [**First Launch**](First%20Launch.md) — install, create your first Template and Data, and run the first Deploy.
2. [**Templates**](Template.md) — define the shape of your data: fields, types, inheritance, components.
3. [**Data**](Data.md) — fill in documents and entries, edit the table, import/export CSV.
4. [**Database**](Database.md) — Local vs Firebase storage, branches, merging and refresh.
5. [**Localization**](Localization.md) — localized strings, languages, and automatic translation.
6. [**Resources**](Resources.md) — how asset references are tracked and shipped with the build.
